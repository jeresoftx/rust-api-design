# Decisión de benchmark: evolución de APIs

**Estado:** draft

No se agrega benchmark ejecutable. El modelo clasifica cambios y valida texto
en memoria; medirlo no cambiaría una decisión sobre compatibilidad, adopción o
retirada de contrato.

Un benchmark sería pertinente si una migración real introdujera una pregunta de
costo reproducible, como transformación de grandes historiales o serialización
dual durante una ventana de coexistencia. Esa medición deberá declarar la
decisión que puede modificar.
