# Decisión de benchmark: operación de APIs

**Estado:** draft

No se agrega benchmark ejecutable. El modelo construye y valida una política
pequeña en memoria; medirlo no decidiría un TTL, un presupuesto de solicitudes
ni una estrategia de recuperación para una capacidad real.

Un benchmark será pertinente cuando una integración concrete una pregunta
reproducible, como el impacto de una estrategia de cache con carga real, la
eficiencia de un algoritmo de límite o el costo de una degradación bajo presión.
La medición deberá nombrar la decisión de ingeniería que puede modificar.
